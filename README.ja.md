# csv-viewer

並べ替え、フィルタリング、画像の埋め込み機能を備えた、CSVデータを表示するためのWebコンポーネントです。

## デモ

**ライブデモ** *(demo unavailable)*

## 機能

-   **表形式での表示**: CSVデータをHTMLのテーブルとしてレンダリングします。
-   **並べ替え**: 列ヘッダーをクリックすると、データをアルファベット順または数値順に並べ替えます。
-   **フィルタリング**: テキスト入力フィールドを使用して、行を即座にフィルタリングします。
-   **画像の埋め込み**: セル内のURLから画像（JPG、PNG、WebP、JPEG）を自動的に検出して埋め込みます。
-   **逆順表示**: 属性を指定するだけで、行の表示順を簡単に逆転できます。
-   **スタンドアロン**: サーバーサイドの依存関係なしに、すべてブラウザ上で動作します。

## 使い方

このコンポーネントは、モダンブラウザではESモジュールとして直接使用でき、レガシーブラウザをサポートする場合はバンドルされたスクリプトを使用して組み込むことができます。

### モダンブラウザ (ESモジュール)

ESモジュールをサポートするブラウザでは、コンポーネントをインポートしてカスタム要素を直接使用します。

```html
<!-- 1. コンポーネントをインポートします -->
<script type="module" src="./csv-viewer.js"></script>

<!-- 2. CSVファイルへのリンクを指定して要素を追加します -->
<csv-viewer src="./test.csv"></csv-viewer>
```

### レガシーブラウザ (バンドル版)

IE11などの古いブラウザ向けには、トランスパイルおよびバンドルされたスクリプトを使用できます。まず、バンドルを生成します。

```bash
npm install
npm run build
```

次に、HTMLファイルに `bundle-es5.min.js` と `custom-elements-es5-adapter.js` を読み込みます。

```html
<!-- ES5環境向けのカスタム要素ポリフィル -->
<script src="custom-elements-es5-adapter.js"></script>
<!-- バンドルおよびトランスパイルされたコンポーネント -->
<script src="bundle-es5.min.js"></script>

<!-- 要素の使い方は同じです -->
<csv-viewer src="./test.csv"></csv-viewer>
```

## 属性

-   **`src`** (必須): 表示するCSVファイルのURL。
-   **`reverse`** (任意): `true` に設定すると、データ行の表示順が逆になります。ヘッダー行は上部に固定されたままになります。

    ```html
    <csv-viewer src="./test.csv" reverse="true"></csv-viewer>
    ```
